Find

No bar. No panel.

The query goes on the status line. Every match on screen fills, and the current one is the selection — so typing over it, copying it and deleting it already work. Nothing is laid over the document, which is the entire point of highlighting it.

⌘F find · ⌘G / ⇧⌘G next, previous · esc done

Chrome

Removed, not hidden.

No sidebar, no toolbar, no title bar. Tabs sit in the band the traffic lights already occupied, so the chrome costs zero editing rows, and the menus live outside the window entirely. Every pixel inside it is drawn from one glyph atlas — there is no AppKit control in there.

⇧⌘P command palette · ⌘O open · ⌘K who's nearby

Together

One network. No cloud.

Beam finds other Beams over Bonjour and pairs in one gesture. Six digits appear on both screens, a human compares them, and the session is encrypted from the first byte. No accounts, no certificates, no server — it works air-gapped.

measured: gesture → digits on both screens 48.7 ms · handshake 0.16 ms

Honestly

What Beam is not, yet.

A project about measurement does not get to be vague about its own state.

  • Sharing is not a CRDT. Two peers share a grid with last-writer-wins on a cell, so typing in the same place at the same moment diverges. Treat it as a demo.
  • No photon numbers are claimed. Software measures “presented”, not photons, and the camera calibration does not exist yet. Every figure here is a software timestamp.
  • Collaboration numbers are loopback. Two processes on one machine — a software floor, never a LAN measurement.
  • Keystroke to pixels is 26 ms on a 60 Hz panel, and about 17 ms of that is present-path depth not yet cut. That work is open, and so is ProMotion.
  • The build is unsigned, and it is Latin, LTR and monospace. No soft wrap, no regex search.
